# Model credits

Optimised copies (textures/UVs stripped, meshopt-compressed) of models distributed with the
three.js examples (https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf):

| File          | Source                         | Author / License |
|---------------|--------------------------------|------------------|
| `soldier.glb` | `Soldier.glb` (Run, Idle)      | Mixamo (Adobe) character + animations, as shipped in three.js examples |
| `xbot.glb`    | `Xbot.glb` (run, walk, idle, sneak_pose) | Mixamo (Adobe) character + animations, as shipped in three.js examples |
| `head.glb`    | `LeePerrySmith/LeePerrySmith.glb` | Lee Perry-Smith, Infinite-Realities — CC BY 3.0 |

Land outlines for the globe come from `world-atlas` (Natural Earth, public domain).
